# 需求记录

本目录按变更保存需求、验收标准和实现结果。每项有实质影响的功能、架构或开发流程变更，都应建立独立记录。

## 命名规则

```text
REQ-YYYYMMDD-NNN-short-title.md
```

- 日期使用需求首次提出日期。
- `NNN` 为当天从 `001` 开始的序号。
- 标题使用简短英文 kebab-case，正文可使用中文。

## 状态

- `提议`：需求已记录，尚未开始。
- `进行中`：正在实现或验证。
- `已完成`：满足验收标准并已提交。
- `已取消`：不再实施，并在文档中说明原因。

## 必填内容

1. 背景与目标
2. 原始需求
3. 范围与非目标
4. 验收标准
5. 设计与实现摘要
6. 修改文件
7. 验证结果
8. 风险与后续事项
9. Git 提交
